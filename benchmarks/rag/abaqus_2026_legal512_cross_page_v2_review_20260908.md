# 表格合法切点 v2：表格解锁，旧题结果不退化

本轮只增加源表格完整行之间的合法切点，并把已有表格标题/附注带到涉及该表的检索块中。表格两题在确定性和LLM两路均为 **2/2**；原有10题的完整召回状态全部保持。梁页6个不支持公式没有修复，仍阻断整页。

## 改动与边界

- 新增独立的 `evaluation/table_legal_boundaries.py`，旧 `legal_boundaries.py` 未改，v1冻结实现hash仍全部匹配。没有改默认索引或产品Agent。
- 从宿主保存的表格XML重新运行既有 `table_projection`，核对整表文本、原先保存的行结束偏移和共享上下文。没有用 `Row` 字样猜测表格，没有新写列解析器，也没有扩展公式或无表头表格支持。
- 每行完整保留列名、值与行内句子；只允许在整行之后切分。标题/冒号引导与首行保持关联。单行超限继续明确失败，不能回退到句子或字符切分。
- 已有表格标题/附注附到每个涉及表格的块的metadata，由原有 `passage_text` 送入重排与返回payload；共享说明同样占用预算。正文和所有gold字符偏移不变，不把重复metadata算成新的原文覆盖。
- 本页没有额外表格附注，实际带回的是原表标题。合成测试另验证了附注传递；不能把该结果外推到尚不支持的复杂跨表脚注。

## 实验控制

沿用六页与十四题，`queries.json`逐字节不变。384-token正文、512-token编码/重排、1,024-token累计返回预算、模型、提示词、Dense20/BM2520与整块选择规则均不变。

四个非表格可处理页复用v1已接受的两路分组，验证新旧chunks JSON hash完全相同；不重新调用LLM，避免随机分组干扰。只有新解锁表格页调用一次Flash。梁页仍不运行分组或检索。

新建两路五页索引后回放全部题目。因此这是带新增表格候选的**开发集回归**，不是同一索引的排名重放，也不是新held-out；不能把均值变化单因果归于行切点，更不能视为Agent收益。

## 结果

| 最大重排pair tokens | 438 | 445 |

表格页原先3,175-token原子现在可在28行间合法切分，最长完整行188tokens。两题分别返回939/962tokens（确定性）和1,013/1,020tokens（LLM），每份实际payload均带回3个表格相关块及各自表格标题；均未截断。

全部12个可处理题的平均实际payload为925.08 / 997.00tokens，Source Recall为0.8333 / 1.0000，必要证据位置Precision为0.2325 / 0.2408。Precision不是穷尽语义相关性标注。原有题目的具体排名/返回长度并非完全不变，只能说完整召回通过/失败状态不退化。

新Flash调用1次，首次接受，4,876 input / 65 output tokens，2.24秒，费用字段不可用。其7个逻辑组经过共同长度保护增加9个边界，最终16块；模型把多数表格行留在一个逻辑组后由长度保护细分。因此表格这两题没有表现出LLM相对确定性分组的收益，结构修复不需要依赖模型来拆行。

## 验证

- 独立于投影实现，直接遍历原表XML的表头和单元格，核对 **28行×4列＝112个单元格**，包括行号、顺序、列名与原值。
- 两路完整重建规范化全文；每行恰好完整归属一个块，无遗漏、重复或行内切断。
- 独立读取每题实际返回payload，验证所有表格相关块的标题均送达，而非仅存在于索引metadata。
- 两个新索引均在查询前绑定语料、BM25数据库、存储向量与HNSW文件；独立评测进程重新打开，前后验证无漂移。
- 相关11个测试文件合计 **116 passed**，其中新增5个表格边界测试；新增实现和正式driver的Ruff/格式检查通过。测试与源码没有进入产品Agent调用链，也未调用Abaqus。

准备阶段曾因Python tuple与JSON list的直接比较报错；在模型调用与实验冻结前修正序列表示比较，并逐字节验证已落盘源文件后继续准备。未覆盖既有源数据、未改题、未重跑已接受模型结果。正式chunk/index/evaluate三个阶段均完成。

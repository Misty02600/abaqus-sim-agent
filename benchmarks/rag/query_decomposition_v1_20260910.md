## 实验如何保持可解释

### 生成阶段

仅给OpenCode Go / `deepseek-v4-flash`原问题、背景和原有product字段，不提供文档、候选列表、目标
段落、gold ID或标准答案。每个原问题最多一次请求，temperature=0、thinking disabled、输出上限1000，
HTTP timeout60秒、HTTP retry0、外层90秒、无输出校验重试。五次使用独立session header，无文件或
检索工具，只暴露typed输出。

`QuestionDecomposition`只允许1–2个不同问句，每条附原输入中的连续引文。引文存在性和新增数值literal
做机械检查，生成后、本次子问题重排前单独人工核对语义，没有修改生成文本。主Agent复核者已知历史
排名，但未见本次子问题排序；记录中的ranking_results_seen=false指后者。五条均允许进入实验；这不构成
严格的语义等价证明。API两问有重叠，warning第二问没有重复第一问的全部背景，这些限制被保留。

生成manifest：`f9db030b9b1cd9af99ffc51b3f71477b350689ca44835b64d10be5848ef4e0a8`。
生成模型的原始request核对为只有原问题数据；所有已知gold ID均未进入其输入。

### 固定池排序与合并

五题都使用上一批page-hybrid的原64条候选，不重新Dense/BM25检索，不增加候选或重建embedding。
基线是当前较好的原问题正文直接重排，不使用更弱的完整背景输入作唯一对照。五条基线的原始分数、
排名和返回证据精确复现旧结果。

每个原样子问题分别用同一cross-encoder重排全部64条，然后按生成顺序轮流从两个排序列表取尚未出现的
父单元。合并只用排名和parent_id，不读取问题、章节名、gold或跨问题logit；最后沿用原交付器的4单元、
正文1200、总证据4000预算。单问时等价于按该问排名进行父单元去重。

排序manifest：`609b5ab905201bc3ceddf3d852cccb87f790f7fadf58ce87d73d06d8eeb3812d`。
实际neural分数保存在逐子问题记录中；融合交付trace中的score是明确标注的序号优先级，不是模型logit
或可信度。回放适配器名为dense的方法也不代表发生向量检索。

### 额外的多方面覆盖检查

在生成前，另固定已有候选池中真正定义载荷比例因子及dead/reference load关系的单元
`993bd2d684857b2bc4ed7cf83be9a8146910beb8215c481a0fc8e70328b13e84`。这项只作为Riks的补充覆盖审计，
不替换原边界条件金标，也不加入原2/3指标的分母，不提供给生成模型。

该LPF定义原基线没有送达，处理后子问题排名22、融合父单元22，仍未送达。正文为917个WordPiece代理
token，低于1200预算；Riks与两条warning没有交付预算拒绝，因此这里不是长度预算导致的遗漏。
未带必要单元标注的API题有一次整体证据预算跳过，原始记录保留，不能说整批零拒绝。

## 开销与验证

- 实际5次生成请求，共3,767 input token、900 output token；生成阶段累计约10.39秒，美元费用不可用。
- 生成9条子问题，处理端重排576个query-passage pair，基线320个，即增加80%，另有生成开销。不是
  同计算预算比较；未把更多推理伪装成免费的检索改善。
- 0新检索、0query embedding、0Abaqus/Solver。没有运行产品CodingRun或其物理oracle。
- 新增13项合同测试通过，覆盖输出数量/问句/重复、输入引文、同池唯一ID、内容冲突、父单元缺失与
  固定轮流去重。全仓868 passed、27项持证测试跳过；新模块BasedPyright及Ruff通过。

新增模块 `evaluation/query_decomposition.py`只保存实验合同和合并函数，没有注册到产品Agent或默认
候选CLI。原索引、默认策略、已有排序模型与全部旧结果保持不变。

## 结论边界

当前这套可选拆分生成器没有提高预声明的必要证据指标；Riks关键题也没有触发真正的双问机制。因此不
将其接入默认，不继续在这五题上改提示直至通过，也不把结果外推为所有查询拆分都无效。

后续若继续处理Riks，应先核对其信息需求、候选证据能支持哪些独立判断及现有排序偏好，再明确新的
可验证假设；不能把“增加一层生成”本身当作解决方案。本轮没有新问题泛化、完整答案或下游任务收益。

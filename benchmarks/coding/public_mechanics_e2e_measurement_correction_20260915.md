# Public mechanics v2：测量错误修正与续批

2026-09-15。v1 实际运行暴露两个宿主错误：LineLoad 的显式 PX/PZ=0 被误判为额外/重叠载荷；脚本重写字节相同的 JSON 未出现在 hash-change 列表，导致错误拒绝正确的再次提取。这些不是 Agent 的物理建模错误。

v1 原始轨迹全部保留。两道杆原正式通过；端载梁因模型请求预算耗尽失败，保留原状态并待终态诊断；均布梁已经因错误反馈反复处理后耗尽模型预算，按测量无效单列；孔板刚开始时因暂停进程树被中断；三维梁未开始。不得把这个批次合并写成四次独立工程失败。

修正仅涉及：

- 物理载荷检查忽略显式零分量，非零错载荷、截面、约束和所有数值容差不变。
- 本评测的 Runner 在每个阶段前后记录声明产物的 SHA-256、大小与 mtime_ns，并绑定完整 execution result 的 hash。只有阶段成功、当前输入相符、输出相符且观测到创建/修改，才接受相同字节重写；旧文件不动仍拒绝。该文件系统见证不是 OS 级防恶意篡改机制。
- 原有 hash-change 证据继续有效；没有新记录的旧轨迹不补造写入见证，也不回填旧 outcome。
- 新批次使用独立 batch id，避免不同批次复用 provider conversation id。

16 项离线回归通过，另有两次真实 Abaqus Python 调用验证相同字节重写见证。没有修改 Agent 产物或 Foundation/题目/容差。

续批为均布梁、孔板、三维梁各一次，使用新源码快照和新绑定，其余模型/工具/预算条件沿用 v1；这是修复测量基础设施后的独立尝试，不是删除旧失败后补齐成绩。所有前批开销继续报告。两道杆不重跑，端载梁不为了凑通过而补跑。

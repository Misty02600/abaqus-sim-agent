# 官方悬臂梁脚本：阅读提示

参考来源为 Abaqus Scripting Guide 的 “The cantilever beam example script”，页面标识 `simacmd-c-intexabeamscript`。代码从本机文档提取，具体来源版本与 hash 由导出目录的 source.json 记录；尚未在本项目执行或适配。官方原稿仅保留在本机资料目录，不作为开源包中的厂商代码发布。

需要参考实体草图/挤出、材料/截面、装配区域、静力步、实例网格等组合方式时，可按需读 `beamExample.py`。文件已有阶段注释，可直接定位，不必加载无关段落。

## 移用前最需要注意的差异

- 这是实体悬臂梁：左端固支、顶部整面压力，采用 C3D8I。不是梁单元或端部集中力示例；解析比较必须匹配其载荷分布、几何与目标量。
- 几何、材料、压力和网格值是示例输入；当前任务使用自己的已知输入。原脚本没有完整单位声明，不能替用户据此猜单位。
- 原稿创建 `dependent=OFF` 实例，并在 Assembly 层播种和划网格。它不能证明当前 Part 网格或 dependent instance 应照用相同调用。
- 原稿启用 `backwardCompatibility`，并使用旧式 tuple 区域。保留原文不代表推荐这些形式；存在接口疑问时查当前 Catalog 或匹配版本资料。
- 视口操作、`submit()`、`waitForCompletion()` 和打开结果显示属于官方教程流程。本项目适配脚本按三阶段工具执行：建模生成 CAE/INP，Solver 工具提交，独立提取脚本读取 ODB。原稿没有本项目要求的 JSON 提取与独立验收。

这些说明用于识别示例与当前任务的差异，不要求每次阅读都重做一套审查，也不授予新的运行权限。

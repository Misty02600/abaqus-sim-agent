## 怎样使用这些结论

同一研究对象的论文与源码分析放在同一份详读中；横向比较与书目索引链接到详读，避免重复维护完整结论。
后续增加项目详读时沿用当前目录，并在此补充阅读入口。

正文区分论文报告、源码观察、分析与迁移建议；本项目实际验证的结果单独标明。提示词要求、代码存在、
Mock 测试和论文成绩，都不自动证明本项目已具备对应能力。

当前采用情况以[架构总览](../architecture/overview.md)、[ADR 索引](../adr/README.md)和
[Coding 评测](../../benchmarks/coding/README.md)、[RAG 评测](../../benchmarks/rag/README.md)为准。

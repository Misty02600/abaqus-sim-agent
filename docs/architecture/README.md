# 架构文档

本目录记录 Abaqus Sim Agent 已确定的系统边界。文档中的“目标”表示已经做出设计决定、但不一定已有
可运行实现；当前实现状态以各文档的状态表和根目录 README 为准。

## 阅读口径

架构使用四层口径：交互层、控制层、执行层和证据层。它们都在同一模块化单体中实现；Abaqus
求解器是受控的外部进程边界。首版不会把每个 Agent 拆成服务，也不会因为目标架构图出现某个组件，
就把尚未实现的能力描述成已有功能。

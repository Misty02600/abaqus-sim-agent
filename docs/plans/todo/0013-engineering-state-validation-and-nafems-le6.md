# PLAN-0013：工程状态验证与 NAFEMS LE6 回归修复

| 状态 | 最后更新 |
|---|---|
| 讨论中 | 2026-09-22 |

## 背景

NAFEMS LE6 skew plate 案例测试中发现，Abaqus Python API 调用可以正常返回，但实际工程状态无效：网格生成后节点和单元数量为 0，后续流程才因缺少中心节点失败。

该问题说明当前 Agent 执行链路需要增加工程状态验证层，不能仅依赖 API 异常判断建模是否成功。

## 目标

- 调查 LE6 案例网格生成失败的真实原因并完成可验证修复。
- 增加 CAE 关键阶段的确定性状态检查。
- 记录 API 执行成功与工程模型有效性的区别。

## 范围

### 工程状态验证

优先覆盖：

- 几何：part、face、vertex 是否存在。
- 网格：node、element、element type、必要 set 是否存在。
- 装配：instance 与命名集合是否有效。
- 求解前：边界条件、载荷和刚体约束基本检查。

### LE6 回归

- 验证当前失败是否来自结构化网格策略或其他建模条件。
- 比较不同网格策略。
- 在 solver 前确认模型具有有效网格和必要输出对象。

## 验收依据

- 保留失败运行证据。
- 新运行记录验证检查结果。
- 区分：API 调用成功、工程状态通过、求解通过、物理结果验证。
